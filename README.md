# InternNova Homepage Redesign Concept

A beginner-friendly responsive homepage redesign made with HTML, CSS, and a small amount of JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — colors, layout, cards, and responsive styles
- `script.js` — mobile navigation and back-to-top button

## Run locally
Open `index.html` in a browser. You can also open the folder in VS Code and use Live Server if it is installed.

## Before submitting
- Review the text and change anything you want to express in your own words.
- Test the page at desktop and mobile widths.
- Check all links and take screenshots.
- Publish the files using GitHub Pages or another static hosting service.
- Add a note in your submission that this is an independent redesign concept, not the official InternNova website.
